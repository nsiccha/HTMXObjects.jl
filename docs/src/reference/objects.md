# Re-exported interfaces

HTMXObjects re-exports object, HTML and HTTP interfaces from its dependencies. The table identifies the defining module; dependency documentation owns those contracts.

```@eval
Main.DocSupport.export_index(:objects)
```

The dependency contracts are maintained in [DynamicObjects](https://github.com/nsiccha/DynamicObjects.jl), [HTMX](https://github.com/nsiccha/HTMX.jl) and [HTTP](https://github.com/JuliaWeb/HTTP.jl).
