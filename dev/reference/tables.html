HTMXObjects.CaptionSpec Type

CaptionSpec(; title, short="", long=nothing)

Caption metadata for a figure or table. title is a short bold heading, short is a one-line summary (typically built from live state so every parameter is visible), and long is an optional longer description shown behind a <details> toggle inside the <figcaption>. The toggle's word is not part of the spec: it comes from the renderer's texts= (caption_texts).

source
HTMXObjects.CaptionTexts Type

CaptionTexts

The words a caption shows besides the caller's own title, summary and long text: more labels the toggle that opens the long text. Build one with caption_texts and pass it as texts= to render_caption or with_caption.

source
HTMXObjects.ColumnSpec Type

ColumnSpec(label; help=nothing, sort_keys=(), align=nothing)

A table column header that carries an explanation, several sort orders, an alignment, or any of them. Use it among the headers of sortable_table (and so of master_detail_table), or as a column of render_table (columns=), wherever a String header would go: the column stays auto-wired exactly like a String — the sort button with keyboard sorting, default_sort by label, the column name in Markdown.

source
HTMXObjects.ColumnSummary Type

ColumnSummary(reduce, values...; digits=0, sigdigits=nothing) ColumnSummary(:tally, item -> category; order=[], label=string, color=nothing, digits=0, sigdigits=nothing)

One column of a group row in a regroupable master_detail_table, computed from the leaves under the group: pass it in group_summary under the column's header label, group_summary = ["Amount" => ColumnSummary(:sum, t -> t.amount)]. The browser computes it again for every grouping the reader picks, so it works in a recorded page with no server.

HTMXObjects.IntervalEstimate Type

IntervalEstimate(estimate, lower, upper; width_digits=2, log=false, digits=nothing, sigdigits=nothing)

Store an estimate and its lower and upper interval bounds as one value. Tables format the estimate together with the interval, using its width to choose display precision.

HTMXObjects.TableTexts Type

TableTexts

The words a table's built-in controls show: the search field, its count and empty state, the selection bar, Expand all / Collapse all, the Group by control, lazy-detail status lines, the CSV button, the toggle of its caption's long text (more, as in caption_texts), the marks of the numbers the table writes (decimal, thousands and the sign of a negative number, minus: - in English, the minus sign − (U+2212) in German; its float cells and number_cells, see format_number, the estimates of format_interval, and the group sums of group_summary in master_detail_table) and the note on a row that holds a hovered item in a collapsed group (linked_inside, linked_deep, linked_inside_many; see Hover linking in sortable_table), the ▾ menu of a column with several sort keys (sort_by, sort_ascending, sort_descending) and the names interval_sort_keys gives its five orders (sort_estimate, sort_lower, sort_upper, sort_width, sort_relative_width; the ⬇ CSV also names an interval column's bounds with sort_lower and sort_upper) and the text of an estimate with its interval (format_interval: interval, 22 (13–34), and interval_signed for a negative bound, -5 (-8 to -2), German −5 (−8 bis −2)) and the range a group summary lies in when a leaf gives its value as bounds (ColumnSummary: range, 9–100, and range_signed for a negative end, -8 to -2). Build one with table_texts and pass it as texts= to sortable_table, render_table, master_detail_table or master_detail_pair.

HTMXObjects.interval_sort_keys Method

interval_sort_keys(estimate, lower, upper; texts=table_texts()) interval_sort_keys(; texts=table_texts())

The five sort keys of a column that shows an estimate with its interval (22 Tsd. (13–34 Tsd.)), for ColumnSpec(label; sort_keys): the estimate, the lower bound, the upper bound, the interval's width (upper - lower) and its relative width ((upper - lower) / abs(estimate)). estimate, lower and upper are functions of the row; the names come from texts (table_texts(:de): Schätzwert, Untergrenze, Obergrenze, Intervallbreite, relative Breite).

HTMXObjects.render_caption Method

render_caption(spec; actions=(), texts=caption_texts())

Return a <figcaption> node for spec, a CaptionSpec or a plain string for a caption with only that title. actions is an iterable of nodes (buttons, links, …) rendered on the right side of the caption header, or in one row below the title in a narrow column (see caption_style). long opens from a small toggle at the end of that row, as a native <details>, so it takes no row of its own until the reader opens it. texts (a CaptionTexts) holds the caption's own words, such as the toggle that opens long; pass caption_texts(:de) on a German page.

HTMXObjects.sortable_table_js Method

sortable_table_js()

Return an h.script(...) node containing the sortTable and htmxoSortState JavaScript functions for click-to-sort table headers, and the rest of the tables' runtime: search, row selection, tree rows, regrouping, row updates and hover linking. It also carries the master/detail row runtime (see master_detail_js). htmx (so pico_page too) carries all of it unless tables=false; include this once per page only in a <head> you build without it. A copy in htmx's extra_head is left out.

sortable_table_styles()

Return an h.style(...) node with the canonical CSS for tables marked class="htmxo-sortable-table": every <th> gets cursor: pointer (sortable by default), and any <th> with a colspan (i.e. a group span over multiple columns) opts out and centres its text.

HTMXObjects.summary_cell Method

summary_cell(summary::ColumnSummary, items; texts=table_texts())

The <td> a group row of a regroupable master_detail_table shows for summary over items: for a row the app builds itself that stands for those items, such as a branch row of a tree grouping (name => :children), so it shows a group's sum or tally exactly as the group rows of the table's other groupings do. A :tally cell's bar takes its length on the scale the column's rows of its level share once the page's table runtime has run. Give a :tally its order (or color) so a category keeps its colour from row to row: without them, the categories take the palette in the order they appear among items.

HTMXObjects.with_caption Method

with_caption(spec, content; actions=(), id=nothing, texts=caption_texts())

Wrap content (a single node or iterable of nodes) in a <figure> with the caption rendered above it. spec is a CaptionSpec, or a plain string for a caption with only that title. Pass actions (e.g. download buttons) to populate the right side of the caption header (below the title in a narrow column), id to give the <figure> an id, and texts (a CaptionTexts) for the caption's own words, as in render_caption.
