HTMXObjects.TestItemInfo Type

TestItemInfo

Metadata for one @testitem discovered without executing its body. key is the canonical relative/file.jl::display name selector passed to the package's test/runtests.jl; id is its URL-safe stable identifier for TestRoutes. An ordinary docstring immediately before @testitem becomes description.

source
HTMXObjects.TestRoutes Type

TestRoutes(; project)

Mount routes for discovering, selecting and running a Julia package’s documented test items. Include this bundle in an @htmx application.

source
HTMXObjects.discover_test_items Method

discover_test_items(project) -> TestCatalog

Discover @testitems with Julia's parser, without importing the package or executing test code. Names, tags, source locations, and adjacent docstrings are returned. Syntax and duplicate-id errors are retained in the catalog for the web UI instead of taking down the host application.

source
HTMXObjects.test_list Method

test_list(project; prefix="/tests", notice="")

Render the current test catalog and isolated run history. The returned value is an ordinary Node; the HTMXObjects response pipeline owns page, fragment, and ?plain rendering.

source
HTMXObjects.test_output Method

test_output(project, id; prefix="/tests")

Render the complete captured output for one validated test job. The main test page keeps large polling fragments bounded and links here without discarding the beginning of the log.
